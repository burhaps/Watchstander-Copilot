# Watchstander-Copilot
Fleethacker challenge

# Objective
Our objective is to create a local Retreival Augmented Generation (RAG) system to assist with the diagnosis and procedures of engineering watchstations in the Navy. When things go wrong, sailors must rely on a wide variety of skills to diagnose and identify the problem. Our goal is to accelerate this process, using machine learning, to quickly identify the likely problem, as well as suggesting solutions to this problem.
